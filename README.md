# 🚩 बिहार दर्शन (Bihar Explorer)

> **Discover the untold heritage, spiritual circuits, and natural beauty of Bihar • Your ultimate bilingual guide**

An immersive, offline-first tourism and encyclopedic platform for exploring Bihar’s ancient history, diverse culture, spiritual circuits (Buddhist, Ramayana, Sufi), and all 38 districts. Built with **React Native**, **Expo**, **TypeScript**, and a vibrant design language.

---

## 🌟 Key Features

### 1. 🏠 Explore & Discover (मुख्य पृष्ठ)
- **Interactive Swiper**: A dynamic, TikTok-style swiper to explore curated "Vibes" like Waterfalls, Mountains, and Hidden Gems.
- **Top Districts & Places**: Quickly access the most popular destinations in Bihar.
- **Smart AI Planner**: Integrated Groq AI to help you plan personalized itineraries.

### 2. 🗺️ Interactive Maps & Circuits (परिपथ एवं मानचित्र)
- **Spiritual Circuits**: Dedicated sections for the Buddhist Circuit (बौद्ध परिपथ), Ramayana Circuit (रामायण परिपथ), Sufi Circuit, and Eco Circuit.
- **Visual Mapping**: Beautiful interactive maps highlighting routes and places.

### 3. 🎬 Bihar Reels (बिहार दर्शन रील्स)
- **Full-Screen Media**: Immersive vertical scroll experience showcasing stunning photography of Bihar's most photogenic locations.
- **Save & Share**: Instantly save your favorite places or share them beautifully with friends.

### 4. 📖 Encyclopedic Knowledge (ज्ञान कोष)
- **All 38 Districts**: Deep dive into the history, geography, economy, and culture of every single district in Bihar.
- **Bilingual Content**: Flawlessly written in both English (visitor-friendly) and formal Hindi (देवनागरी).
- **Rich Markdown**: Beautifully formatted historical articles and facts.

### 5. 📴 100% Offline Capability
- All core text, district profiles, historical data, and place information work completely offline without an active internet connection.

---

## 🛠️ Tech Stack & Architecture

- **Core Framework**: React Native (v0.76+ / RN 0.86), Expo SDK 52, TypeScript
- **Navigation**: Expo Router (File-based routing with custom floating blurred tab layout)
- **AI Integration**: Groq API for lightning-fast, conversational travel planning
- **State & Storage**: AsyncStorage for favorites and user preferences
- **CI/CD**: Fully automated Fastlane & GitHub Actions deployment to TestFlight

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn
- Expo Go app on mobile (or Android Studio for emulator)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/amit265/bihar-explorer.git
   cd bihar-explorer
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npx expo start
   ```

4. **Run on Android / iOS**:
   ```bash
   npx expo run:android
   npx expo run:ios
   ```
